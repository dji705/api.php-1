# API לעיבוד טקסט באמצעות שירות AI

המאגר מכיל כרגע קובץ PHP יחיד (`api.php`) שמקבל טקסט בפרמטר URL בשם `text`, שולח אותו בבקשת POST לשירות חיצוני, ומחזיר למשתמש את שדה `response` מתוך תשובת JSON.

## אופן הפעולה

1. קריאת הפרמטר `text` מתוך query string.
2. אם לא נשלח טקסט, מוחזרת הודעת שגיאה בעברית.
3. נבנית בקשת JSON עם הטקסט ונשלחת באמצעות cURL.
4. התשובה מפוענחת כ-JSON; אם קיים שדה `response`, תוכנו מוחזר. אחרת מוחזרת הודעת שגיאה.

## דרישות

- שרת PHP עם cURL מופעל.
- גישה לרשת אל כתובת השירות החיצוני.
- מפתח API תקף, שיוגדר מחוץ לקוד.

## דוגמת שימוש

```text
https://YOUR-HOST/api.php?text=שלום
```

הקוד מחזיר טקסט פשוט ולא פורמט ייעודי של ימות המשיח.

## מצב ומגבלות

זהו אבטיפוס ראשוני. כתובת השירות בקוד נראית ככתובת placeholder/כתובת שדורשת אימות, ולכן אין להניח שהחיבור פעיל. יש לבדוק את כתובת ה-API, את מבנה הבקשה ואת שמות השדות מול תיעוד הספק לפני שימוש.

**אבטחה:** בקובץ המקור הנוכחי מוטמע מפתח API. יש לבטל/לסובב אותו מיד, להנפיק מפתח חדש ולהעבירו למשתנה סביבה או למנגנון סודות של סביבת האחסון. אין להעלות מפתחות ל-Git.
